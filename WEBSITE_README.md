# MergeBounty Website Package

Use the files below as the handoff package for a website generator:

1. `PROJECT_OVERVIEW.md` — product problem, solution and trust model.
2. `WEBSITE_HANDOFF.md` — canonical facts, required sections and accuracy rules.
3. `WEBSITE_CONTENT.md` — finished website copy.
4. `FRONTEND_INTEGRATION.md` — contract-facing frontend guidance.
5. `WEBSITE_DATA.json` — canonical addresses, hashes, evidence and transaction data in machine-readable form.
6. `WEBSITE_BUILD_PROMPT.md` — complete production build prompt.
7. `WEBSITE_DELIVERY_CHECKLIST.md` — what to return after generation.
8. `SUBMISSION_EVIDENCE.md` — canonical live proof trail.

The public website may be built independently from the immutable adjudicated developer commit. After the site is generated, provide the final ZIP/source plus live URL and the repository documentation can be updated with the website without changing the exact reviewed evidence commit.
