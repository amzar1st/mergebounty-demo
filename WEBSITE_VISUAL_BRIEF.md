# MergeBounty Visual Brief

## Brand feel

Technical, credible, modern, audit-oriented, and developer-first. The site should feel like infrastructure for verifiable software commerce rather than a memecoin or generic crypto landing page.

## Suggested visual language

- dark charcoal/navy base;
- restrained violet/cyan/electric accents;
- thin borders and subtle glow rather than heavy neon;
- monospace treatment for hashes, addresses and transaction IDs;
- small status pills such as `APPROVED`, `FINALIZED`, `1 GEN`, `Studionet`;
- Git commit / hash / validator-node motifs;
- evidence flowing into independent validators and converging on a settlement state;
- transaction timeline as a primary proof element;
- high legibility and strong spacing.

## Hero visual concept

A compact evidence flow diagram:

`Immutable Requirements` → `Exact Commit + SHA-256 Evidence` → `GenLayer Validators` → `Consensus Verdict` → `Escrow Settlement`

The flow can animate subtly but must remain readable and performant.

## Avoid

- generic coin piles;
- excessive glowing blockchain cubes;
- fake dashboards with invented metrics;
- stock photos;
- loud cyberpunk overload;
- claims of guaranteed security or fraud-proof settlement.

## Mobile

On mobile, prioritize:

1. value proposition;
2. verified `APPROVED` demo card;
3. contract + commit/evidence proof;
4. transaction timeline;
5. architecture explanation.

Long hashes should truncate visually but retain copyable full values.
