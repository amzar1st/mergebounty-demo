Give the website generator these files together:

- PROJECT_OVERVIEW.md
- WEBSITE_HANDOFF.md
- WEBSITE_CONTENT.md
- FRONTEND_INTEGRATION.md
- WEBSITE_DATA.json
- WEBSITE_BUILD_PROMPT.md
- WEBSITE_VISUAL_BRIEF.md
- WEBSITE_ARCHITECTURE.md
- WEBSITE_SECURITY_COPY.md
- WEBSITE_FAQ.md
- WEBSITE_TEST_PLAN.md
- SUBMISSION_EVIDENCE.md

Then paste `WEBSITE_PROMPT_SHORT.txt` or the full `WEBSITE_BUILD_PROMPT.md` as the build instruction.

Do not ask the generator to alter the GenLayer contract or the immutable reviewed developer commit. Its job is the presentation/frontend layer only. After generation, return the final source ZIP plus live public URL so the main repository documentation can be updated with the website evidence.
