# Reviewer path

A reviewer should be able to evaluate MergeBounty in this order:

1. `README.md` — concise project summary and live lifecycle.
2. `SUBMISSION_EVIDENCE.md` — canonical Studionet proof trail.
3. Exact reviewed commit and commit-bound `EVIDENCE.md` — implementation evidence.
4. Public website — presentation of the verified lifecycle and architecture.
5. `PROJECT_OVERVIEW.md` — deeper trust-model explanation if needed.

The website must complement, not replace, the canonical on-chain and commit-bound evidence.
