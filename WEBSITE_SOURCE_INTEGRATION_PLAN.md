# Website source integration plan

When the generated website is delivered:

1. Review the ZIP for buildability and canonical data accuracy.
2. Confirm whether the site is static proof, live read-only, or wallet-connected.
3. Add the frontend source under a dedicated `frontend/` directory unless the generated project structure strongly requires another layout.
4. Keep the immutable `developer-submission` reviewed commit unchanged.
5. Add the live website URL to `README.md` and `SUBMISSION_EVIDENCE.md`.
6. Record frontend framework, build instructions and deployment provider in the frontend README.
7. Verify the canonical contract, commit, evidence hash and transaction trail one last time before GenLayer submission.
